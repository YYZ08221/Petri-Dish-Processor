# CBL 培养皿图片批量处理系统

把实验照片中的培养皿识别出来，逐个检查、旋转，再裁剪成独立图片。适合批量整理涂布照片、制作实验记录和准备后续分析素材。

这是 **Windows 本地桌面程序**，使用 Python、PySide6 和 OpenCV。照片在本机处理，无需 API Key、在线 AI 服务、GPU 或模型权重。当前版本负责培养皿定位与图片整理，**不包含菌落计数或生物学结果判读**。

## 功能

| 功能 | 说明 |
| --- | --- |
| 批量导入 | 读取所选文件夹直接包含的 JPG、JPEG、PNG、TIF、TIFF，不递归读取子文件夹 |
| 自动定位 | 原图显示培养皿圆框和编号，列表显示检测数量 |
| 检测模式 | 自动、单培养皿、多培养皿 |
| 手动修正 | 新增和删除圆框、移动圆心、调整半径、撤销、重置、跳过 |
| 全图旋转 | 左转或右转 90°，圆框位置同步变化 |
| 单皿旋转 | 每个培养皿独立设置角度，步长 1°，实时查看裁剪预览 |
| 裁剪形状 | 方形，或圆形区域外填黑 |
| 导出 | 当前图自定义命名，全部导出按原图名加序号 |
| 处理记录 | CSV 记录圆心、半径、裁剪范围、角度和输出路径 |

原始照片不会被修改。自动识别后需要检查圆框，尤其是反光、遮挡、亮背景、培养皿贴边或明显倾斜的图片。

## 安装与启动

### 1. 环境要求

- Windows 10/11，64 位。
- 64 位 Python 3.11 或更新版本。首次安装推荐 Python 3.11 或 3.12，安装时勾选加入 PATH。
- 首次安装需要网络下载依赖，装好后处理本地图片无需联网。
- Git 克隆需要 Git，下载 ZIP 的方式不需要 Git。

本仓库是源码版，不是免安装 EXE。依赖见 [requirements.txt](requirements.txt)。

### 2. 下载代码

**下载 ZIP：** 在仓库页面点击 **Code → Download ZIP**，解压，将包含 `app.py` 的那一层文件夹命名为 `CBL`。建议位置：

```text
D:\程序\涂布处理系统\CBL
```

**Git 克隆：** 打开 PowerShell 执行：

```powershell
git clone https://github.com/YYZ08221/CBL-Petri-Dish-Processor.git "D:\程序\涂布处理系统\CBL"
cd "D:\程序\涂布处理系统\CBL"
```

路径可以自选，没有 D 盘时可用 `C:\Tools\CBL`。程序使用相对路径，不绑定盘符。已有目录非空时，请先备份或另选空目录。

### 3. 一键安装并检查

在包含 `app.py` 的目录中打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -RunTests
```

脚本创建项目内 `.venv`、安装依赖、验证界面构建和合成图片导出、运行测试。不会修改系统级执行策略。可省略 `-RunTests`，基础安装检查仍会执行。

基础检查成功时会显示：

```text
PASS: dependencies, offscreen GUI, crop export, and CSV log
CBL installation verified. Start with: .\.venv\Scripts\python.exe app.py
```

真实照片测试依赖未公开参考图，缺少图片时显示 `skipped` 是预期。基础检查通过不代表任何照片都能准确识别。

### 4. 启动程序

双击 **启动程序.bat**，或者运行：

```powershell
cd "D:\程序\涂布处理系统\CBL"
.\.venv\Scripts\python.exe app.py
```

无需手动激活虚拟环境，使用 `.venv` 内的 Python 即可。

### 手动安装

```powershell
cd "D:\程序\涂布处理系统\CBL"
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/check_install.py
.\.venv\Scripts\python.exe app.py
```

没有 `py -3.11` 时，可用已安装的 64 位 Python 3.11+ 执行 `python -m venv .venv`。

## 第一次使用：完整流程

1. 将照片放在同一文件夹内，先用 2～3 张熟悉操作。
2. 点击右侧 **选择输入文件夹**，后台开始逐张检测，底部显示进度。
3. 点击左侧文件列表，在中间查看照片和绿色圆框。列表包含文件名、状态、数量。
4. 检查圆框是否贴合培养皿外沿、数量是否正确。**需确认** 表示需要人工检查，不代表报错。
5. 识别数量不对时选择检测模式，点击 **当前图重新检测**。仅修改参数不会自动重算。
6. 手动修正圆框，点击一个圆框，在右侧查看对应裁剪预览。
7. 用 **全图旋转** 调整整张照片方向；用预览区角度输入框独立调整某个培养皿。
8. 设置裁剪系数、裁剪形状和格式，有需要时选择输出文件夹。
9. 点击 **导出当前图**，输入文件名，检查一次实际导出效果。
10. 检查其余照片，等后台检测完成后点击 **全部导出**。没有圆框的图片会被跳过。

当前没有项目保存/恢复功能。调整保存在本次运行会话中，退出前请导出。

## 检测模式与参数

| 模式 | 当前行为 | 适合情况 |
| --- | --- | --- |
| 自动 | 优先定位浅色培养皿区域，用轻量多圆检测补充尺寸接近、位置分离的候选 | 日常单皿、双皿混合文件夹 |
| 单培养皿 | 优先区域分割，仅保留一个最可信圆 | 明确只有一个培养皿，或自动模式出现假圆 |
| 多培养皿 | 使用原多圆检测流程保留多个候选 | 明确有多个培养皿，或自动模式漏掉第二个 |

自动模式是图像处理规则，不是通用 AI 物体识别模型。第二培养皿的判断依赖尺寸、位置和圆形边缘等特征，仍可能漏检、误检。改变光照、背景和培养皿大小会影响结果。

| 参数 | 默认值 | 解释 |
| --- | --- | --- |
| 裁剪系数 | `1.10` | 输出边长 = 圆框直径 × 系数；增大可保留更多周边，只影响裁剪 |
| 最小半径 | `120` | 以原图像素计的最小候选半径；小培养皿漏检时可适度降低 |
| 最大半径 | `0` | `0` 表示按图片尺寸估算上限；可填写像素值限制过大的假圆 |
| 检测灵敏度 | `55` | 主要影响多圆检测，提高可能发现更多圆，也可能增加误检；区域分割不直接使用此值 |

修改参数后点击 **当前图重新检测**。后台批量任务使用开始时的参数，需要按新参数重跑整个文件夹时重新选择输入文件夹。重新导入会清除当前会话调整，请先导出需要保留的结果。

## 手动修正圆框

| 操作 | 方法 |
| --- | --- |
| 缩放 | 滚动滚轮 |
| 平移 | 按住右键或中键拖动 |
| 选中 | 点击对应圆框内部 |
| 移动圆心 | 左键在圆内拖动 |
| 改变半径 | 左键拖动圆框边缘 |
| 新增圆 | 点击 **新增圆**，再点击培养皿中心，然后调整半径 |
| 删除误检 | 选中误检圆，点击 **删除当前圆** |
| 清空 | 点击 **清空当前圆** |
| 撤销 | 恢复上一次记录的圆框编辑 |
| 重置 | **当前图重置** 恢复最近检测记录的圆框 |
| 排除照片 | **跳过当前图** 会让导出忽略该图 |

建议圆框对齐外沿，再用裁剪系数留边。

## 旋转和裁剪预览

**全图旋转：** 左转 90°、右转 90° 或重置；原图与已有圆框同步变化，导出采用相同方向。

**单培养皿旋转：** 先选中圆框，在右侧预览区输入角度，步长 **1°**，范围 `-180°` 到 `180°`。可用 `-90°`、`+90°` 或重置。每个培养皿的角度独立保存。

预览和导出先取更大范围并旋转，再裁剪最终小图，减少先裁后转造成的黑边。如果原照片边缘没有足够内容，仍会填黑。

**圆形裁剪：** 输出仍是矩形图片文件，圆形区域外填黑，**不是透明背景**。支持 JPG、PNG、TIF。方形裁剪保留培养皿和周边留边。

## 导出、命名与 CSV

### 导出当前图

弹框内输入文件名主体，例如 `PBS-65`，不用输入扩展名：

| 培养皿数量 | PNG 输出示例 |
| --- | --- |
| 1 个 | `PBS-65.png` |
| 2 个 | `PBS-65-1.png`、`PBS-65-2.png` |
| 更多 | 继续追加 `-3`、`-4` 等 |

取消或输入空名称会取消导出。Windows 禁用字符会替换为下划线，建议使用文字、数字、短横线和下划线。

### 全部导出

使用 **原图名主体-培养皿序号.扩展名**。例如 `51.tif` 中有三个培养皿，输出 `51-1.tif`、`51-2.tif`、`51-3.tif`。圆框按位置近似从上到下、从左到右编号。当前图输入过的自定义名不会用于全部导出。

**原格式** 保留输入扩展名，也可以统一导出 `png`、`tif`、`jpg`。

### 输出目录

- 未指定输出目录：在输入文件夹下新建 `processed_YYYYMMDD_HHMMSS`。
- 指定目录：在所选目录内新建上述时间戳子目录。
- 已有同名文件会追加时间戳等后缀，避免覆盖。
- 导出后右侧显示实际输出目录；下一次导出会以当前显示目录为基准再建子目录，需要换位置时重新选择输出文件夹。
- 被跳过、没有圆框的图片不会输出。

每次导出生成 `processing_log_YYYYMMDD_HHMMSS.csv`，包括原图名、输出名、序号、圆心、半径、裁剪边长、系数、形状、全图角度、单皿角度、人工调整标记、处理时间和输出路径。

导出完成表示写入文件完成，识别正确与否仍需要查看圆框和输出图片。

## 常见问题

### 双击启动没有界面

在 PowerShell 执行 `.\.venv\Scripts\python.exe scripts/check_install.py`，再运行 `.\.venv\Scripts\python.exe app.py` 查看错误。确认当前目录包含 `app.py` 和 `src`。依赖缺失时重新运行安装脚本。

### Python 不存在或版本错误

安装 64 位 Python 3.11+，重开 PowerShell，用 `python --version` 或 `py -3 --version` 检查。脚本优先使用 `py -3`。多版本环境可以手动指定版本创建 `.venv`，旧环境不适合时使用新的克隆目录安装。

### 依赖下载失败

检查网络与 pip 的具体错误，再重跑安装脚本。首次安装需要联网。不要从不可信来源下载 DLL 替换系统文件。

### 单培养皿出现多个圆

切换 **单培养皿**，点击 **当前图重新检测**。反光、划痕、标签、背景纹理都可能产生假圆，可人工删除并调整主圆。

### 两个培养皿只识别一个

切换 **多培养皿** 后重新检测。仍漏检可调整半径约束或手动新增。自动模式不保证找全所有培养皿。

### 修改参数后没有变化

必须点击 **当前图重新检测** 并等待完成提示。已经启动的后台任务使用开始时的参数，不会自动重算全部照片。

### 小图预览为空

先点击一个圆框选中培养皿。没有圆框时需要重新检测或手动新增。

### 圆形图片四角为什么黑色

圆形裁剪就是圆外填黑。方形旋转图片出现黑边则可能是裁剪范围超出原照片，照片之外没有可用内容。

### 全部导出数量少了

检查后台检测是否完成、对应照片是否有圆框、是否被标记跳过。输出数量以培养皿为单位，不是以原图为单位。

### 换电脑可以直接复制 .venv 吗

建议在新电脑重新执行安装脚本，虚拟环境可能带旧电脑路径，不适合作为可移植包。重新在界面选择照片和输出目录即可。

## 测试与开发

```text
CBL/
  app.py                  桌面入口
  启动程序.bat            双击启动
  requirements.txt        依赖（包含 pytest）
  README.md               用户说明
  AGENTS.md               Agent 安装与维护约定
  scripts/
    install.ps1           安装、检查、可选测试
    check_install.py      无窗口界面构建与合成图导出检查
  src/
    core/                 检测、读写、裁剪、旋转
    gui/                  主窗口和画布
    models/               图片与圆框数据
    services/             导出与 CSV
    utils/                文件名与目录工具
  tests/                  自动化测试
  .github/workflows/      Windows CI
```

```powershell
.\.venv\Scripts\python.exe scripts/check_install.py
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m pytest -q
```

`offscreen` 用于无窗口测试。手动启动 GUI 前请在新 PowerShell 窗口运行，或清空该环境变量。基础检查脚本仅在自己的进程中设置此值。

真实照片回归测试默认读取 `tests/reference_images`，也可设置：

```powershell
$env:CBL_REFERENCE_DIR = 'C:\Data\CBL-reference-images'
.\.venv\Scripts\python.exe -m pytest tests/test_detection_reference_images.py -q
```

需要的文件名见 [参考图测试](tests/test_detection_reference_images.py)。仓库不包含实验原图，没有图片时会跳过。GitHub Actions 在 Windows 上安装依赖、运行基础检查和可用测试，不能据此推断真实图片识别成功率。

更新程序时，在没有未保存代码改动的工作目录执行 `git pull --ff-only`，然后重新运行安装脚本。修改检测算法时，需要经授权的单皿、多皿照片回归，不能只检查圆的数量。

## 数据和功能边界

- 公开代码、文档和安装工具，不上传实验原图、导出结果、私人备份、缓存和虚拟环境。
- 本地处理图片，用户通过界面选择目录。
- 当前没有菌落计数、命令行批处理、自然语言图片处理接口、项目会话恢复。
- 检测结果依赖拍摄条件，需要人工复核。
